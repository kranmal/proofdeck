Proofdeck

Self-hosted test management in the style of Zephyr Scale. By kranmal.

Proofdeck is a server app with a database, so it can't run on this page. Run it on your own machine or server; it takes one command.

What it does

  • Test cases with steps, folders, versions, templates and Gherkin or Excel import
  • Cycles and runs, with a step-by-step test player that works on a phone, camera included
  • Bugs linked to Jira, GitHub, Linear, Azure DevOps and GitLab, with webhooks both ways
  • Dashboard, weekly email report, comments, @mentions, saved views and a trash with undo
  • Sign-in with OIDC single sign-on or TOTP two-factor, plus live updates between users
  • Import from Zephyr Scale and JUnit results

Run it

Needs Node 22 or newer. There are no packages to install.

git clone https://github.com/kranmal/proofdeck
cd proofdeck
npm start        # http://127.0.0.1:4780

The first visit creates the admin account. Data lives in data/; back it up with sqlite3 data/proofdeck.db ".backup 'copy.db'".
